# Asisten CS Cerdas (Intelligent Customer Support Agent)

An open-source intelligent customer support agent and document context analysis framework built for real-time customer service automation.

## Features
- **Contextual Document QA**: Ingests company documentation, FAQs, and product catalogs to provide grounded answers.
- **Agentic Multi-Step Reasoning**: Capable of decomposing user queries and formulating accurate replies.
- **Privacy First**: Fully self-hostable with configurable LLM providers.

## Getting Started
```bash
git clone https://github.com/anzelsgaming-commits/Asisten-CS-Cerdas.git
cd Asisten-CS-Cerdas
pip install -r requirements.txt
streamlit run app.py
```
